AUTOMATIC PHOTO DOWNLOADER + SORTER (no API key)

This script searches publicly indexed images and downloads them into the correct TXT/ENHYPEN member folders. It then rebuilds photos.json automatically.

FIRST TIME ONLY
1. Open Command Prompt inside this susu-gallery-starter folder.
2. Install the free Python package:
   py -m pip install ddgs
3. Run the downloader:
   py download_photos.py

By default it aims for up to 25 images per member (12 members = up to 300 images). Existing images count toward each member's target, and exact duplicate files are skipped. You can choose a different target, e.g. 40 per member:
   py download_photos.py 40

IMPORTANT
- Internet access is required. Some image hosts block automated downloads and search providers may rate-limit requests, so it may download fewer than the target. Run it again later to try again.
- Search results can be the wrong person or fan edits. Check the folders and remove bad images; the script cannot guarantee identity.
- Only use images in ways allowed by their source/license. This is a personal-gallery helper, not permission to republish copyrighted images.
- The script does not download from private accounts or bypass logins/paywalls.
- After it finishes, run the site with `py -m http.server 8000` and open http://localhost:8000.


NEW PHOTO COUNT: Double-click ONE_CLICK_DOWNLOAD.bat and enter the number of NEW images you want it to try downloading for EACH member. Example: 50 means up to 600 new images across 12 members. Actual totals may be lower because of duplicates, blocked hosts, or search limits. Existing images are kept.
